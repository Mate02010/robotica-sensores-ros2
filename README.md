# Práctica de sensores con ROS 2

- **[RPLIDAR 2D](lidar/):** controlador sllidar_ros2, lectura de barridos, filtros, parámetros y grabación.
- **[Cámara PrimeSense](camara/):** controlador OpenNI2, imágenes de profundidad, filtros y grabación.

**[Ver video de la prueba física del RPLIDAR](evidencias/videos/RPLIDAR_prueba_fisica_2026-11-13.mp4)**

Entorno utilizado: Ubuntu 24.04 / WSL 2 y ROS 2 Kilted. Controladores: [sllidar_ros2](https://github.com/Slamtec/sllidar_ros2) y [openni2_camera](https://github.com/ros-drivers/openni2_camera/tree/jazzy).
